## 0. 这一段在整片里的职责

这是全片**唯一一段命令语气**（家族 A：Switch / Remember / Lay / Fill / Set up / let's begin）。后面全部歌词都是条件句或独白。

所以这一段的视觉任务只有两个：

### 第 1 行 · 00:00.03 `Switch on the power line`

**左窗**
```
我：学长，软件学院大一，报到了。还没开学，我先给板子通上电。
小天：欢迎来到西北工业大学。长安校区，东祥路1号。
      你手上那块是 UNO，插上 USB 就能亮 —— 但你得先把电源线接对。
```

**右区**：全屏黑。00:00.03 起，PCB 走线图案**从左下角一根一根亮起**，电流沿走线推进（不是整体淡入，是**真的在走**）。走到底板边缘时出现 `VCC` / `GND` 丝印。

**转场**：这是全片第一帧，无转场。但右区必须在 0.0s 时**全黑**，0.03s 才对上第一个词——**第一帧不许提前有画面**。

**词级钩子**：`Switch` 落在走线通电的第一根；`power` 落在整板点亮；`line` 落在唯一一根还没接的线**闪红一下**（这是后面所有"报错"的第一次预告，不给台词）。

### 【器乐空隙】00:12.47 – 00:29.28（13.14 s，本批次内必须有自己的镜头）

**这一段没有歌词**，是全片第一个留白。绝不能"上一句还挂着"。设计成**一次静默的自检**：

**左窗**（航小天单方面输出，我不说话）
```
小天：趁它跑，我说一下这四年的安排。
      大一：嵌入式电子微系统、程序设计（C）。
      大二：软件工程、面向对象、计算机网络、计算机操作系统、计算机组成原理、数据库。

      你会觉得它很长。它确实很长。

                              用时 2.3秒
                              00:14
```

**右区**：**课程表逐行滚动**打印（不是弹出），像终端 `cat` 一个课表文件；每行左边是学年，右边是课程。滚完之后画面停在最后一行不动，只有光标在闪。

**词级钩子**：无歌词。用**行打印节奏**对齐音乐：每 1.4 s 一行（接近 130 BPM 的 3 拍），滚完 9 行约 12.6 s，正好卡到 00:29.28。

### 第 9 行 · 00:29.28 `If I'm a set of point`

**左窗**
```
我：学长，我问个可能有点蠢的问题。
    这些数学，到底有什么用？
小天：不蠢。这是这四年最该问的问题。
      如果我是点集，我就把维数给你。
```

**右区**：★ **条件句机制的第一次出场**。画面右侧出现一个**空的"如果—那么"双格框**（这是全片后面要重复十几次的装置，第一次必须把它的读法教清楚）：

```
┌ IF ──────────────┬ THEN ─────────────┐
│  a set of point  │                     │
└──────────────────┴─────────────────────┘
```

左格填入 `a set of point`，**右格空着**——留到第 10 行填。同时画面上散落**离散的点**（不是网格，是散点，因为歌词说的是"点"不是"网格"）。

**转场**：MORPH。待机态那行时间戳**散开**成这些点——时间戳变成点，是"从时间进入空间"。

**词级钩子**：`If` → 双格框出现；`I'm` → 左格标题亮；`a` / `set` / `of` / `point` → 四个词依次落下，**`point` 落下的同时右边散点出现**。

### 第 10 行 · 00:30.89 `Then I will give you my dimension`

**左窗**
```
小天：维数。
      一个点没有长度，但一堆点可以有一维、二维、三维。
      你将来写图形程序，第一件事就是决定你有几维。
```

**右区**：散点**聚成一条线**（一维），再**扫成一个面**（二维），再**拉成一个体**（三维），每升一维，双格框的右格填一次：
```
┌ THEN ─────────────────────┐
│  dimension: 1 → 2 → 3      │
└───────────────────────────┘
```
三维成形的一刻，整个体**闪一下**，然后塌回散点——为下一句的"圆"做准备。

**转场**：无（同一镜头内延续）。这是条件句的设计原则：**IF 和 THEN 在同一镜头里完成**，不许切开——切开就变成了两张卡片。

**词级钩子**：`Then` → 点开始聚；`I` / `will` / `give` → 升维；`you` → 右格开始写；`my` / `dimension` → 三维成形并闪烁。
