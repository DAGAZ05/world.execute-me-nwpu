# 批次 16 验证记录：构图（去杂乱 + 非矩形 panel）

按你这次的三条：**构图不要显得杂乱**、**panel 可以是圆形/正多边形/蜂巢**、**架构不要频繁变**。
所以这一批不动架构、不加新层，只做两件事：**把"杂乱"变成可量的东西**，然后按量出来的结果改。

出图：`04_验证记录/批次16_构图/`。

## 1 新增 `_dev/density_probe.py`：把"杂乱"量出来

杂乱是判断，但它的两个成因是计数：

| 指标 | 含义 | 判定 |
|---|---|---|
| `ink` | 有内容的格子占比 | `>0.55` **WALL**：整屏都是墨，已经不成其为图 |
| `bands` | 横向连续有内容的"带"数 | `>7` **STACKED**：一摞东西，不是一张图 |
| `text` | 有内容的行里"以中文为主"的比例 | `>0.30` **TEXTY**：是页面不是画面 |
| `gap` | 最长连续空行 | `>9` **PATCHY**：中间有个洞 |

第一版用"带数 > 4"当判据，**51 个 pane 里报了 36 个**——一张图加上表头、机身、一行机件就是三带，
这个判据等于没有。改成上面四个之后报 17 个，而且头几名确实是真问题。

## 2 按量出来的结果改（两处）

### `pane_gauge_fem`：**0.87 的墨 → WALL**

有限元网格原来是**从边到边铺满整框**的 `─` 和 `┼`，那不是网格，是一堵墨墙。
现在**只画在零件上**：一个翼型剖面（前缘厚、后缘薄、带弯度线），零件外面什么都不画——
这也正是仿真软件里看到的样子。墨量 0.87 → **0.45**，WALL 判定消失。

### `pane_ai_diffusion`：**0.44 的墨 + 8 带 → STACKED**

两个原因，都改了：四格噪声 → **三格**（t=2/t=1/t=0，同样说清楚，少三分之一墨）；
干净那一格原来把**心形之外的整块背景**都画成 `░`，等于给最安静的一格上了满屏底纹——
现在**形状之外什么都不画**。墨量 0.44 → **0.37**。

### 其余两处**判定为假阳性**，记在这里而不是硬改

- `pane_exec_net` 12 带：**时序图本来就是一排一排**的，11 条消息各占一行；
- `pane_ai_diffusion` 仍是 8 带：术语表按"每行之间空两行"排开，是留白不是堆叠。

判据应该被理解成"去看一眼"，而不是"必须改"。

## 3 非矩形 panel：嵌入式课换成蜂巢

你这次允许 panel 不是方的。字符格里**最适合的非矩形是正六边形**——`_`、`/`、`\` 正好是它的三条边。
所以 `c_embedded` 从"一个矩形框标着 UNO R3 + 四条跳线"改成**蜂巢**：

```
      ___     ___     ___
     /   \   /   \   /   \
     \ TRIG─●\ ECHO●──  LCD/
      \   /   \   /   \   /
       ___     ___     ___
                 │
                ___
               /   \
               \  UNO/
                \   /
                 ___
                 │
       ___     ___     ___
      /   \   /   \   /   \
      \ SDA●─\  SCL─●─  GND/
       \   /   \   /   \   /
        ___     ___     ___
```

中间是控制器，六个外设围一圈，总线走在**格子之间的缝**里，脉冲按歌曲时钟沿总线跑。
**缝是有意义的**：矩形面包板画到 95 格宽就是"一个框加几条线"，而框是让 pane 显得挤的主要原因。

新增的 `hexagon()` 是通用原语（`_Kit` 上），以后别的 pane 要正多边形可以直接用。

顺带修掉蜂巢第一版的三个几何错误：顶边高一行、环间距少两行（六边形互相压成一片散乱的斜杠）、
总线走到了邻居格子**内部**把它的标签擦掉（应该只走两格宽的缝）。
