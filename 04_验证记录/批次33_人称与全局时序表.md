## 1 人称代词：`her` → `figure` / `mascot`

这套播放器是从原片 fork 的，数据模型里继承了原片对主角的说法：`ent["her"]` 的意思是"这一镜的左栏可以
显示主角"。在**原片**变体里那位主角是 大肥鱼（她），所以 `film_panels.shots()["her"]` 这个名字是对的、
保留不动；但在**本变体**里那位主角是 航小天，于是项目里唯一还把他叫 "her" 的地方就是这些字段名。

| 位置 | 改前 | 改后 | 说明 |
| --- | --- | --- | --- |
| `school_panels.py` 日程行（63 处） | `her=True/False` | **`mascot=True/False`** | 这一行是"航小天可否占左栏"，用他自己的说法 |
| 播放器入口键（两处构建站点） | `her=self.her_drawn(…)` / `her=bool(row.get("her"))` | **`figure=…`** | 两个变体共用：原片是 大肥鱼，本变体是 航小天 —— 中性名字对两边都成立 |
| `tui_live.py` 读取 | `ent["her"]` | **`ent["figure"]`** | 同上 |
| 高度常量 | `HER_MIN_H, HER_MAX_H` | **`FIG_MIN_H, FIG_MAX_H`** | 它量的是"可能放主角的那块 pane"，与性别无关 |
| 原片专用标记 | `e["last_her"]` | **`e["last_figure"]`** | 只由 `tui_live` 写、`her_style` 读 |
| 本变体自己的注释（4 处） | "her world" / "her=True on a row means…" / "ME_TEXT stays hers" | "the film's own world" / "`mascot=True`…航小天" / "stays the film's" | 说的是本项目的主角就用他，说的是原片主角就点明是原片 |
| 探针 | `sweep_tui.py` 的 `e["her"]` | `e["figure"]` | 它读的是播放器条目 |

**没动的**：`her_glyphs.py`、`film_panels.shots()["her"]`、`her_style` / `draw_her` / `her_keeps_pane`
（这些是原片的绘制路径，主角真的是她），以及 `mascot_glyphs.py` 里本来就写对的
"**The palette is his, not hers**"。

验证：全仓 `grep '\[.her.\]|\bher=(True|False)|HER_M[IA]X|last_her'` 只剩 0 处（原片模块外）；
`python -c "import school_panels…"` 通过；`check.cmd` 全过（下同）。

## 2 时序对照：全局文档 + 每批次强制更新

原来每个批次的记录里各带一份 `时序对照表.md`（批次 31、32），是"快照"。现在改成**一份常驻的全局文档**：

| 文件 | 是什么 |
| --- | --- |
| **`06_时序对照表.md`**（项目根目录，395 行） | 全局时序文档，**生成物**，每批次必须重生成 |
| `06_时序对照表.tsv` | 同一份数据的机器可读版 |
| `_dev/timeline_doc.py` | 生成器；`--check` 只比较、不写 |

### 文档的七节

| 节 | 内容 |
| --- | --- |
| 头部 | 怎么更新、由什么统计出来（78 行 / 98 歌词 / 75 块 365 行对话 / 15 整屏事件 / 65 panel）、每列的含义、明确不列 `feature bands` 与 `progress` |
| **1 逐行日程**（78 行） | 时间 · 镜头（原片 97 镜名）· 区间内全部歌词 · 对话 · panel · 代码自己的说法（docstring 首句）· ops · 整屏层事件 · **核验结论** |
| **2 逐句歌词**（98 行） | 每一句歌词落在哪一行日程、那一行画什么、那一句的对话 |
| **3 panel 清单**（65 个） | 出现时间 · 代码自己的说法 · **渲染读回的屏上文字** · 核验结论 |
| **4 整屏层 / 窗口层 / 震屏** | 15 个整屏事件（含素材名、尺寸、caption）+ 篮球窗口 + 震屏 |
| **5 对话全文**（75 块） | 按时间，标出每块挂在哪句歌词、当时哪张 panel，逐行角色（我 / 航小天 / 副行 / 代码块 / 卡片 / 元信息） |
| **6 变更历史** | 批次 22–33 各一行，指向 `04_验证记录/` 的记录 |
| **7 已接受的例外** | 校徽/铸剑的重复、专业段 ops 是清单、篮球窗口盖住会话、受框大小限制的三处绘制、boot log 的专业内容 |

### "每一批次要修正"是被机器保证的

`check.cmd` 新增一条：

```
=== timeline_doc    the global timeline document: is 06_ (the table) still current
python _dev\timeline_doc.py --check || set FAIL=1
```

`--check` 重新生成一遍并和磁盘上的文件逐字比较；日程、对话、panel 的屏上文字、整屏层表只要有一处变了
（或者有人手改了文档），`check.cmd` 就判失败并打印要跑的命令。README 的状态表里也加了这一行。
