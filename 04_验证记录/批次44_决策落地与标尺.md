## 2 对话雕塑的第三段：从"时钟猜"改成"日程说"

### 2.1 原来错在哪

`pane_landmark_dialogue` 的三段是**一行之内的三个相位**，由行内已用时间切换：

```python
phase = 0 if lt < 1.2 else (1 if lt < 2.4 else 2)
```

那一行是 54.74–60.57，于是第三段（`只剩那颗星`）落在 **~57.1 s**——正是 `If I can, if I can`，
而 `02b §3.3` 把它钉在 `If I'm the only God`。**这张表要避免的错位，恰恰是代码造成的。**

### 2.2 改法：相位由日程指定

```python
def pane_landmark_dialogue(..., phase=None, max_phase=2):
    if phase is None:
        phase = 0 if lt < 1.2 else (1 if lt < 2.4 else 2)
    phase = max(0, min(int(phase), int(max_phase)))
```

日程：

| 行 | args | 内容 |
|---|---|---|
| 54.74–60.57 | `dict(max_phase=1)` | `unite` 两只手靠近、`deeply` 手指间的星 |
| **84.60–86.21** | `dict(phase=2)` | **`the only God` 只剩那颗星**（`If I'm the only God`） |
| 86.21–88.34 | — | `pane_motif_stardiff` 顺延到 `Then you're the proof of my existence` |

这是 `pane_memory` 用 `args` 传层数的**同一个机制**：日程说这是哪一张，而不是绘制从时钟猜。

> `stardiff` 顺延的理由：星芒作"存在的证明"比压在 `only God` 上更贴，而 `only God` 那 1.61 s
> 交给唯一有"神性"的那张素材。

实测：54.74 那行在 0.1/0.5/0.9 三个采样点**都不再出现** only-God 段；
84.60 行正确显示 `只剩那颗星` 与 `the only God`，且 `lyric == "If I'm the only God"`。

## 4 数学表达增益：量化的图有了刻度

审计的 §四类增益第一条是"补真实坐标轴数值刻度"，第二条是"补色阶 legend"。

### 4.1 `_ds_curves`：有轴无名、有名无数

这张图的内容**就是**三条增长率的序与量级（`log n` < `n log n` < `n²`，在每一个 n 上），
而它只有两行说明「横轴 = 元素个数 n」「纵轴 = 操作次数（取对数）」，**一个数字都没有**。
**量级需要标尺。**

补上：

- **x 轴 4 个刻度**（`┬`）与数值（n = 1…N 的等分点）；
- **y 轴十进制量级刻度**（`├`）：纵向标尺是 `log2(1 + ops)`，所以十进制落在 `log2(1 + 10**kk)`，
  在刻度左侧标出 k = 0,1,2；
- 说明改为 `n = 1…N   纵轴 10^k 次操作`。

实测：**x 刻度 4 个、y 量级刻度 3 个、两轴都有范围与单位**。

### 4.2 我自己撞上的一个冲突（探针当场抓到）

第一版把两行说明留在原来的 `by1-4` / `by1-2`。探针报：

```
x axis named with a range: False;  y axis named as 10^k: True
```

**x 轴那行没上屏，y 轴那行在——只差一行。** 原因是 `draw_course` 在**绘制之后**还会画
课程术语表、且横跨整个 pane 宽度：**画得越靠下，越可能被它盖掉**。

改法：**把整个标尺移到图的上方**（`by0 + 1`），并让绘图区在 `by1 - 7` 收尾（原来 `by1 - 4`），
把这层耦合彻底去掉。代价是曲线区少 3 行——换来标尺不可能再被术语表吃掉。

### 4.3 `g_attention`：热力图没有量阶

格子按概率着色，而屏上**从没说过哪个字形代表多大把握**——最亮与最暗之间只有"更多"和"更少"，
读不出 55% 与 12% 的区别，而那正是热力图唯一被问的问题。

补一行量阶 legend：`legend  ░≥.10 ▒≥.25 ▓≥.55 （行归一）`。

### 4.4 `c_dl`：曲线与图彼此无关（批次 43 留下的松口）

批次 43 把 `c_dl` 改成真的前向/反向计算图，但曲线仍标着 `loss 0.xxx`，
与下面那张网络**没有名字上的联系**。现在曲线标为 **`L(W₁,W₂)`**，与图里的末节点 `L` 同名同物。
