## 1 魔鬼鱼"不太干净（有杂项）"

> 魔鬼鱼的图像似乎不太干净（有杂项）

先把"哪里脏"量出来，而不是先调参数：把素材单独画成图（新的一页 `_dev/sprite_shot.py`：用事件自己的
`lift/span/ambient` 贴到空屏上导出 PNG），再把精灵的每个格子按颜色分类打成一张字符图
（`. none / # 亮 / o 中性 / b 偏蓝`）。结论：

- 素材是**抠图**（74 % 像素 alpha=0），但**水里的背景是不透明的**：不透明像素里 11 % 是海军蓝 `(0,0,32)`、
  6 % 是青 `(0,32,32)`（水面的焦散），下采样之后成了鱼**周围**几片蓝色楔形；
- `ambient`（批次 50 为"黑底黑体"加的**颜色下限**）会给**每一个有墨的格子**加同一个量，于是这些背景片
  被抬成灰蓝色块，压在字符场上就像几块脏斑（字符被它们盖掉，正是"不干净"的样子）。

试过两条**都不行**的路，都记在代码里：

| 办法 | 结果 |
|---|---|
| 把 alpha 门槛从 96 抬到 168（`ALPHA_FLOOR`） | 只去掉 44 个最淡的格子，杂项一个没少——它们 alpha=255，本来就是"实心"的 |
| 颜色键"暗且偏蓝就删" | 画面干净了，但**鱼的翅膀也一起没了**：`(32,64,96)`、`(48,68,88)` 与背景同色，是水反光下的翼面 |

最后分开它们的是**距离**，不是颜色：鱼是"亮格 + 中性格"组成的实体，蓝色只出现在**贴着**这些实体的
翼面；背景的蓝楔离任何实体都有十格以上。于是新写 `_clean()`（`CLEAN = {"manta": 1}`）：把"亮（均值>120）
或中性（通道差≤12）"的格子当作实体，按 `k` 格做一次方形膨胀，膨胀之外的墨格全部透明。`k` 是看着图定的：
`k=3` 还留着背景楔的边缘，`k=1` 干净且鱼的轮廓、尾、翼尖、卷起的头鳍都在。

## 2 铸剑雕塑出现前的 `git bash`

> 学院部分最后面 exec 框在铸剑雕塑出现前，将该 panel 抬头改为 git bash，下面内容为：
> `(hangxiaotian) git commit -m "今天又认识了一位新同学，期待ta毕业的一天"`

- `school_panels` 新增 `GIT_FROM, GIT_TO = 199.00, 203.00` 与 `GIT_LINE`——两端都是**事件**（航小天全身退场
  199.00、铸剑雕塑闪现 203.00），不是估的；`ops_machine(t, ops)` 在这个窗口里返回
  `{"title": "git bash", "rows": [GIT_LINE], ...}`；
- `tui_live.draw_ops` 的抬头原本写死 `"exec"`，现在读 `machine["title"]`（缺省仍是 `exec`）——面板抬头
  由内容自己声明，而不是由绘制端假设。

**渲染时立刻撞出一个真缺陷**：`_draw_machine` 假定"内容行数 ≥ 面板行数"，面板给它 6 行而内容只有 1 行，
于是 `rows[idx]` 越界抛 `IndexError`（整个事件被 `draw` 的 `except` 吞掉，屏幕上那一格就是空的）。
改成超出内容就停（余下的行留白），并把 `top` 的钳位补上 `max(0, …)`。

## 5 这一批的教训

**"图"和"文件"不是一回事：抠图的背景可以是实心的。** `魔鬼鱼.png` 74 % 透明，所以我一直当它是干净的
抠图——而它不透明的那 26 % 里，有六分之一是水。`ambient` 是给"黑体在黑底上"加的**颜色下限**，
它按"有墨"给量，于是把背景也一起点亮了：一个为 A 问题加的开关，在 B 问题上变成了副作用。
**先看素材、再看渲染**（这一步这一批做了三次：单独导出精灵、按颜色分类打图、放大看帧），比调三个参数快。

**"中心裁剪"是这套图的一个反复出现的坑，而它只在"框是扁的"时候显形。** 同一个 `sprite`，同一张正方形
徽记：`flash` 在批次 25 修过、`emerge` 到这一批才修。两个调用点的差别只是**谁算这个框**——
一个算"图能有多大"，一个算"我想要多大"。**凡是要格子数的地方，都要问一次图自己的长宽比。**

**新内容第一次上屏要真的去渲染。** `git bash` 那一格写完之后跑一次回溯，才看见 `IndexError` 被
`draw` 的 `except` 吞掉：`_draw_machine` 与"内容行数"之间的隐含约定（≥ 面板行数）从来没有被任何探针
碰过——因为在这之前**每一个**内容都恰好有 8 行，而面板最多给它 6–8 行。**一个只被一种数据验证过的
函数，遇到第二种数据就会炸。**
