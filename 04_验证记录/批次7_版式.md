# 批次 7 验证记录：版式

本批次只改**版式**——左栏、右栏、pane 高度、ops 框——但版式一动，右栏每一张图都要
重新审一遍，因为它们原来都是按 11 行高画的。所以这份记录里有一半是"图撑不满高框"的清单。

对应你第 7 条：左栏太宽、右侧视觉太小、有图时 ops 框要短。

## 2 版式改动抓出来的三个真缺陷

### 2.1 CJK 是按"字"裁的，不是按"格"裁的（严重度 高）

`_Kit.put()` 原来写 `text[:room]`，`caption(right=True)` 原来写 `len(text)`。
中文一个字占**两格**，而 `Screen.put` 也是按两格推进的——于是任何靠右对齐的中文标签
都会从 pane 右边漏出去。`pane_probe` 在 118×11 / 118×9 直接报 `LEAK 3`：

```
leak 121  5 '等'     ← "黑高相等" 的最后一个字
leak 121  6 '邻'
leak 120  7 ')'
```

修法不是在那一处减 3，而是给整套裁剪换成按格算：新增 `_cells()`（east_asian_width）、
`_clip()`、`_pad()`，`put/caption/_header` 全部改用它。这条同时解释了原来那张
"对照表列对不齐"的观感——`"数组".ljust(14)` 补的是 14 个**字符**，也就是 18 格。

### 2.2 完全二叉树的深度公式写错了下标（严重度 高）

`d = i.bit_length() - 1` 是**从 1 开始编号**的结点深度；根结点 `i=0` 因此得到 `d=-1`，
横坐标算到列外 80 格、纵坐标算到 pane 上面去。症状很隐蔽：只有"每层最左边/根"这几个
结点不见了，边线从列外斜插进来。改成 `d = (i+1).bit_length() - 1`。

### 2.3 标签补空格把箭头线擦了（严重度 中）

TCP 时序图里消息标签原来写成 `lab + " " * (room - len(lab))`，补到整条链路宽度，
于是**把刚画好的横线擦掉**，只剩远端一个箭头。11 条消息里 6 条变成"光箭头"。
改成只写标签本身，线在字后面继续。另外把生命线从 `bx0+3` 挪到 `bx0+12`，
左边留出 12 格给"三次握手 / HTTP / 四次挥手"三个阶段名。

## 3 右栏高框之后：哪些图撑得满，哪些撑不满

`draw_course()` 现在这么做：先让图按整框画，然后**问屏幕**图用到哪一行（`_last_ink`），
把该课程的"术语 · TERMS"填在剩下的行里，并按剩余行数把这些术语摊开——
所以撑不满的图不再是一条黑带，而是"图 + 术语表"，术语表一直排到框底。

这样做的理由写在代码里：定一个固定高度给术语表**不解决问题**，黑带只是从框底挪到
图与术语表之间（第一版就是这样，`pane_exec_c` 中间空了 20 行）。

下面是 113×36 框里"最后一个高密度行"的实测（`≥6 格墨`算一行）：

| pane | 图用到 | 空 | 处理 |
|---|---|---|---|
| `pane_exec_net` | 9 | **27** | ✅ 本批重画：11 条消息摊满全框 + HTTP + 四次挥手 + 阶段名 |
| `pane_exec_db` | 7（+1 条底注） | **26** | ✅ 本批重画：三层 B+ 树（root→internal→leaf 扇形） |
| `pane_exec_os` | 16 | 18 | ✅ 本批加图：`top` 表下面接三栏——进程状态机 / 地址翻译 / 调度时间片 |
| `pane_exec_oop` | 7（生命线到 36） | 中段空 | ⏳ 待办：类图只有 3 个成员；补"继承链 + 接口实现 + 多态分派" |
| `pane_exec_industrial` | 17 | 19 | ⏳ 待办：等轴测装配体要加零件表 / 爆炸视图 |
| `pane_exec_dl` | 33 | 3 | 尚可 |
| `pane_exec_embedded` | 32 | 4 | 尚可 |
| `pane_gauge_final` | 8 | 28 | 故意的：毕设甘特图只有一条线，是那个笑点 |
| 其余 9 张 | 29～36 | 0～7 | 由图 + 术语表填满 |

术语表本身是内容，不是填充：每门课 9 条，英文在前、中文释义在后
（`school_courses.DETAIL`）。挑的是考试、手册、报错信息里真正会出现的词，
比如 `buffer overflow / 越界写，第一个安全漏洞`、`TLD miss → 查表`、`attention / 注意力：让模型自己选看哪里`。
