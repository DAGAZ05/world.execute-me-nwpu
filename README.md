窗口拉到 **175 列 × 52 行**以上（懒得数就按 Alt+Enter 全屏）。字体用 Windows Terminal +
Consolas/微软雅黑这类回退组合，老的 `cmd.exe` 会把块状字符显示成方框。

按键与原包一致：空格播放/暂停，`←/→` 5 秒，`,`/`.` 1 秒，`h` 换画法，`c` 换左窗，

**歌曲**：`player/input/song.mp3` 不在包里（版权）。没有歌曲也能跑（静音，时钟走系统时间），
画面、歌词、对话一切正常。要加歌曲见 `player/怎么加歌曲.txt`。

不按就在窗口结束时报软件学院，页脚会一直提示。想跳过这段过程就加 `--major s` 预答；
拖动进度条整段跳过时按"假定软件学院"处理，不会把预答当成真答。

## 改编做了什么、没做什么

**做了三件事**（播放器 3,569 行没有重写）：

1. `--variant` 换数据模块：`school_panels` 用模块级 `__getattr__` 转发 `film_panels`，
   只覆盖真正改掉的名字（左窗内容、右栏 pane、ui 增益）。
2. `draw_body` 里三处变体判别：谁拥有左窗、右栏画哪个 pane、pane 函数从哪来。
3. `draw_dsh` 多一个 `window=` 参数，让左窗内容可以从外面递进来。

歌、时钟、剪切、歌词带、逐词打字、跑马灯、进度条**全部沿用原片**。

**故意没做的**：

- **不改歌词**。英文原文逐词打字保留原样，中文对照也保留。歌词是权威来源。
- **不抄原片的"她的世界"面板**。右栏换成西工大的学科内容，而不是给鲸鱼的面板换标签。
- **不复用 `ui_gain_at` 的褪色曲线**。原片那条曲线说的是"你走了，系统色就褪"，
  航小天没走，那条 cue 在这个变体里不存在。原因写在 `school_panels.py` 的文档字符串里。
